Carmel International School

Privacy Policy

Effective Date: 30 July 2026

This Privacy Policy explains how Carmel International School collects, uses, stores and protects information when using the School Management System application developed by Skiez Technologies Ind Pvt Ltd.

1. Information We Collect

The application may collect the following information.

Student Information

  • Name
  • Roll Number
  • Admission Number (Optional)
  • Gender
  • Date of Birth
  • Blood Group
  • Class
  • Section (Optional)

Parent Information

  • Name
  • Phone Number
  • Email Address

Teacher Information

  • Name
  • Gender
  • Email Address
  • Phone Number
  • Joining Date
  • Qualifications
  • Years of Experience
  • Address

2. Photos and Documents

Authorized users may upload:

  • Student Photos
  • Teacher Photos
  • Homework
  • School Notices
  • PDF Documents
  • School Circulars
  • Other School Related Documents

These files are securely stored using Firebase Storage.

3. Authentication

The application uses Firebase Authentication for secure login.

Only accounts created by the School Administrator can access the application.

Public Sign Up is not available.

4. Push Notifications

The application uses Firebase Cloud Messaging (FCM) to send:

  • Homework
  • School Notices
  • Announcements
  • Emergency Alerts
  • Important School Updates

5. How We Use Information

  • Manage Student Records
  • Manage Teacher Records
  • Attendance Management
  • Homework Management
  • Notice Management
  • Parent Communication
  • School Administration
  • Send Push Notifications
  • Improve Application Performance

We do not sell or rent user information.

6. Data Storage

The application uses:

  • Firebase Authentication
  • Cloud Firestore
  • Firebase Storage
  • Firebase Cloud Messaging

Reasonable security measures are used to protect user information.

7. User Access

Only authorized users can access the application:

  • School Administrator
  • Teachers
  • Parents

8. Account Management

Accounts are created and managed by the School Administration.

Users cannot register or delete their own accounts.

For account deletion requests, users should contact the School Administration.

9. Children's Privacy

This application is intended for educational institutions. Student information is managed only by authorized school staff and parents.

10. Data Security

We implement reasonable technical and organizational measures to protect user information. However, no electronic storage or internet transmission method is completely secure.

11. Third-Party Services

  • Firebase Authentication
  • Cloud Firestore
  • Firebase Storage
  • Firebase Cloud Messaging

12. Changes to this Privacy Policy

We may update this Privacy Policy from time to time. Updated versions will be published on this page.
